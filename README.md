# 🧠 Memory Game

A classic, interactive card-matching game that tests and improves your memory. Built with vanilla JavaScript, HTML5, and CSS3.

## 🎯 **Purpose**

This project demonstrates fundamental web development concepts:

- **DOM Manipulation** - Dynamic card creation and updates
- **Event Handling** - Click events for card flips and game logic
- **State Management** - Tracking game state (matches, moves, timer)
- **CSS Animations** - Smooth card flips and transitions
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Game Logic** - Matching algorithm, win conditions, timer

---

## ✨ **Features**

| Feature | Description |
|---------|-------------|
| **Card Matching** | Flip two cards and find the matching pairs |
| **Move Counter** | Tracks every move you make |
| **Timer** | Starts when you make your first move |
| **Star Rating** | Lose stars based on move count (optional) |
| **Restart Button** | Reset the game board anytime |
| **Win Condition** | Congratulatory message when all pairs are found |
| **Responsive Design** | Playable on all screen sizes |
| **Keyboard Accessible** | Full keyboard support |
